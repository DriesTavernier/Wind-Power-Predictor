\# Wind Power Predictor



Predicting wind turbine power output from SCADA data, comparing a theoretical model, linear regression model and a neural network against the turbine's power curve.



\## Data



SCADA data from a wind turbine: wind speed, wind direction, theoretical power curve and measured active power.



\- Source: https://www.kaggle.com/datasets/berkerisen/wind-turbine-scada-dataset?resource=download

\- Raw file: `data/raw/wind\_turbine\_scada.csv`



Files in `data/clean/` (cleaned data, features, train/test splits, predictions) are generated by the pipeline and are not stored in Git.



\## Approach



1\. \*\*Data exploration and cleaning\*\*: quality checks and removal of invalid records

2\. \*\*Feature engineering\*\*: exploring power difference and using cp

3\. \*\*Train/test split\*\*: 80/20

4\. \*\*Models\*\*: linear regression and a neural network 

5\. \*\*Evaluation\*\*: RMSE, MAE and bias

\## How to run



```bash

git clone https://github.com/DriesTavernier/wind-power-predictor.git

cd wind-power-predictor

python -m venv .venv

.venv\\Scripts\\activate

pip install -r requirements.txt

python main.py

```



Run `main.py` from the project root. It executes the full pipeline and shows the evaluation plots.



\## Project structure



